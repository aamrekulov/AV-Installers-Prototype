# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

A marketing site for "Minimalist AV", a luxury home cinema / smart home installer. Originally exported as a **Figma Make** code bundle (see `package.json` name `@figma/my-make-file`) and now maintained directly as a Vite + React app.

## Commands

Package manager is **pnpm** (see `pnpm-workspace.yaml` / `pnpm-lock.yaml`), though `package.json` scripts are npm-style:

```bash
pnpm i          # install deps
pnpm dev        # start Vite dev server
pnpm build      # production build (vite build)
```

There are no lint or test scripts configured — don't invent commands that aren't in `package.json`.

## Architecture

- **Entry**: `src/main.tsx` → `src/app/App.tsx` → `RouterProvider` using `src/app/routes.ts`.
- **Routing**: `react-router` `createHashRouter` (hash-based, e.g. `/#/home-cinema`) with `Root` as the layout shell and pages as children (`index` → `Home`, `home-cinema` → `HomeCinema`).
- **`src/app/Root.tsx`** owns the persistent nav bar and footer around `<Outlet />`. Cross-page nav links use `scrollIntoView` for in-page anchors and fall back to `navigate("/", { state: { scrollTo: id } })` when the target section isn't on the current page.
- **Pages** (`src/app/pages/Home.tsx`, `HomeCinema.tsx`) are large, self-contained single-file sections (700–1000+ lines each). Each page defines its own local design-token constants (`DARK_BG`, `ACCENT`, `EASE`, `TRANS`, etc.), its own `scrollToSection` helper, and its own scroll-reveal `IntersectionObserver` hook — these are **duplicated per page, not shared**. When editing one page's visual language, check whether the same tweak needs to be copied into the other page rather than assuming a shared source of truth.
- **Styling**: Tailwind v4 via `@tailwindcss/vite` (see `postcss.config.mjs`, `src/styles/tailwind.css`), combined heavily with inline `style={{ }}` objects for anything using the hex/rgba design-token constants. `src/styles/theme.css` defines shadcn-style CSS custom properties (`--background`, `--accent`, etc.) and a `.dark` variant, but the pages mostly bypass these tokens and hardcode their own hex values instead — the two systems are not kept in sync.
- **`src/app/components/ui/`** is the full shadcn/ui component set generated by Figma Make. It is currently **unused** — no page or `Root.tsx` imports from it. Don't assume a UI change should touch these; check whether the page actually renders raw JSX/Tailwind instead before reaching for a shadcn primitive.
- **Images**: static assets live in `src/imports/*.webp` and are imported directly by path (e.g. `import heroImg from "../../imports/hero.webp"`). `HomeCinema.tsx` also references some hotlinked `images.unsplash.com` URLs directly in data arrays.
- **`vite.config.ts`** registers a custom `figma-asset-resolver` plugin that resolves `figma:asset/*` imports to `src/assets/` — this is Figma Make scaffolding; `src/assets/` doesn't currently exist and no code uses `figma:asset/` imports, so treat this as inert unless new Figma-exported code reintroduces it. The React and Tailwind Vite plugins are both required even where Tailwind classes aren't used — don't remove them.
- **`guidelines/Guidelines.md`** is an authoritative visual design spec (colors, type scale, spacing, component recipes, motion timing, absolute bans) for this brand. Consult it before making styling decisions — it documents the intended system even though the current page code doesn't fully reference it via CSS variables.
